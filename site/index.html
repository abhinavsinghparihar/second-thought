Manual install. Second Thought is not on the Chrome Web Store. You load it yourself in developer mode, and Chrome will not update it for you: to update, download the newest ZIP and repeat the steps below.

Installation guide

  1. Download second-thought-extension.zip with the button above.
  2. Extract the ZIP into a folder you will keep (Chrome reads it from there, so do not delete it afterwards). That folder must contain manifest.json directly.
  3. Open chrome://extensions in a new tab.
  4. Turn on Developer mode (top-right switch).
  5. Click Load unpacked.
  6. Select the extracted folder that contains manifest.json.
  7. Click the puzzle icon in the toolbar and pin Second Thought. Then open Settings and add a Groq, Gemini, OpenAI or Anthropic key. It is stored only on this device.

Chrome may show a “Disable developer mode extensions” prompt at startup. That is normal for manually loaded extensions. Only install ZIPs from this repository’s Releases page.
