2Analysis engine

Engine

3Sites

Second Thought will ask for permission to run on these sites. Detection is heuristic; use with judgment. localhost is allowed for testing with the MockChat page.

4Privacy

Second Thought analyzes requests on-device by default. Prompt history and analytics are off by default. In AI-powered mode, the request text is sent by your browser directly to the provider you configured — never to us. There is no Second Thought server involved in refinement. See the privacy documentation for details.
